# 🎬 Netflix Data Analysis

## 📌 Project Overview
This project explores the Netflix Titles dataset using Python to uncover insights about Netflix's content library. The analysis focuses on content type, release trends, genres, countries, directors, ratings, and movie durations through data visualization.

---

## 🎯 Objectives
- Clean and preprocess the dataset
- Explore trends in Netflix content
- Visualize key insights using charts
- Practice Exploratory Data Analysis (EDA)

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub

---

## 📂 Dataset
**Dataset:** Netflix Titles Dataset (`netflix_titles.csv`)

---

## 📊 Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Movies vs TV Shows
- Content Released by Year
- Top 10 Countries
- Top Genres
- Top Directors
- Content Ratings
- Movie Duration Analysis

---

## 📈 Key Insights
- Movies make up a larger portion of Netflix's catalog than TV Shows.
- The United States contributes the highest number of titles.
- Drama and International Movies are among the most common genres.
- Netflix experienced significant content growth after 2015.
- TV Shows generally have fewer entries than Movies.
