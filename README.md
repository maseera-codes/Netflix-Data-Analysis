# 🎬 Netflix Data Analysis

## 📌 Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python to uncover trends and insights.

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed
- Movies vs TV Shows
- Content added over the years
- Top 10 countries producing Netflix content
- Most popular genres
- Ratings distribution
- Movie duration analysis

## 📈 Key Insights
- Movies make up the majority of Netflix content.
- The number of titles added increased rapidly after 2015.
- The United States contributes the highest number of titles.
- Drama and International Movies are among the most common genres.
